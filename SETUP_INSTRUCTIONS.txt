STEP 5: CONFIGURE ENVIRONMENT
=============================

Copy environment template:

  cp .env.example .env

Edit .env and fill in these required values:

  # Database
  DB_USER=urbanhelp_user
  DB_PASSWORD=your_secure_password

  # JWT Secrets (generate random strings)
  JWT_SECRET=your_random_jwt_secret_here
  JWT_REFRESH_SECRET=your_random_refresh_secret_here

  # Stripe (get from https://dashboard.stripe.com)
  STRIPE_SECRET_KEY=sk_test_...
  STRIPE_PUBLIC_KEY=pk_test_...
  STRIPE_WEBHOOK_SECRET=whsec_test_...

  # Twilio (get from https://www.twilio.com)
  TWILIO_ACCOUNT_SID=your_twilio_account_sid
  TWILIO_AUTH_TOKEN=your_twilio_auth_token
  TWILIO_PHONE_NUMBER=+1234567890

  # SendGrid (get from https://sendgrid.com)
  SENDGRID_API_KEY=your_sendgrid_api_key

  # AWS (if using S3 for uploads)
  AWS_ACCESS_KEY_ID=your_aws_access_key
  AWS_SECRET_ACCESS_KEY=your_aws_secret_key
  AWS_S3_BUCKET=urbanhelp-images

  # Google Places (for address autocomplete)
  GOOGLE_PLACES_API_KEY=your_google_places_api_key

TROUBLESHOOTING
===============

Q: Docker services won't start
A:
  docker-compose down -v
  docker-compose up -d --build

Q: npm install fails
A:
  npm cache clean --force
  rm -rf node_modules package-lock.json
  npm install

Q: "Port already in use" error
A: Change ports in docker-compose.yml or stop other services:
  lsof -i :3000  # Find what's using port 3000
  kill -9 <PID>

Q: Database connection failed
A: Check .env database credentials match docker-compose.yml

Q: "Module not found" errors
A: Make sure all TIER*.ts files are copied to backend/src/
